# Hyper Widget Pack

Набор минималистичных виджетов для [Rainmeter](https://www.rainmeter.net/) (Windows): CPU, RAM, сеть, видеокарта, диски, погода и корзина. Каждый виджет живёт отдельно, его можно перетаскивать, и он магнитится к соседям и к краям экрана с ровным отступом 10 px. Темы общие для всех, а размер, прозрачность и вид у каждого виджета свои.

Почти всё настраивается прямо на рабочем столе через **правый клик по виджету**, в файлах ничего править не нужно.

## Установка

1. Поставить [Rainmeter](https://www.rainmeter.net/) 4.5 или новее.
2. Поставить шрифт [JetBrains Mono](https://www.jetbrains.com/lp/mono/).
3. Скопировать папку `HyperWidgets` в `Документы\Rainmeter\Skins`.
4. Правый клик по значку Rainmeter в трее → **Refresh all**, затем в **Manage** включить нужные виджеты (`HyperWidgets\CPU\CPU.ini` и т.д.).

Для GPU нужна видеокарта NVIDIA: данные берутся из `nvidia-smi`, который ставится вместе с драйвером. Погода приходит с [Open-Meteo](https://open-meteo.com/), ключ API не нужен.

## Общие настройки (правый клик по любому виджету)

| Пункт | Что делает |
|---|---|
| **Themes...** | Окно выбора темы: Graphite, Warm, GitHub, Kanagawa (у каждой есть светлая и тёмная версия), Catppuccin Latte / Frappé / Macchiato / Mocha. Там же режим **Light / Dark / Auto**: Auto подбирает светлую или тёмную версию под яркость обоев. |
| **Align all here** | Выравнивает все виджеты по левому краю этого. |
| **Size: 75 / 100 / 125 / 150%** | Размер только этого виджета. |
| **Opacity: 40 / 60 / 80 / 100%** | Прозрачность фона только этого виджета. |
| **Edit settings file** | Открывает `@Resources\Variables.inc` с остальными настройками. |

Виджеты CPU, RAM, NET, GPU и DISK дополнительно умеют:

| Пункт | Что делает |
|---|---|
| **View: list / rings** | Вид списком с полосками или кольцами. |
| **Title: show / hide** | Показать или скрыть заголовок. |

При наведении строки и кольца плавно подсвечиваются и немного увеличиваются.

## Виджеты

### CPU
Загрузка процессора и load average за 1 / 5 / 15 минут, как в `top` или `btop`. Он считается как активные потоки плюс очередь процессора, со сглаживанием. В виде колец показаны загрузка и load за 1 минуту в доле от всех потоков.

### RAM
Занятая и общая память, плюс SWAP (файл подкачки).

### NET
Скорость приёма и отдачи. Сетевая карта задаётся в `NetInterface` в `Variables.inc`: значение `Best` выбирает её автоматически, но может выбрать VPN-туннель. Скорость, при которой кольцо заполняется полностью, задаётся в `NetMaxDown` / `NetMaxUp`.

### GPU
Загрузка, видеопамять и температура видеокарты NVIDIA через `nvidia-smi`. Частота опроса задаётся в `GpuRate`.

### DISK
Основной диск выделен, ниже до трёх дополнительных. **Клик по заголовку → «Set disks...»**: введите буквы, например `C: G: D:`, первая станет основным диском.

### WEATHER
Сейчас: описание погоды и «ощущается как». Ниже график на 24 часа: столбики температуры, дождь и снег, жёлтым фоном отмечен световой день. При наведении на столбик он подрастает и показывает температуру и час. **Клик по названию города** позволяет ввести другой город, координаты найдутся сами.

### RECYCLE
Сколько весит корзина и сколько в ней файлов. Полезно, если значки на рабочем столе скрыты.
- **Клик:** открыть корзину.
- **Клик колёсиком:** очистить корзину, Windows спросит подтверждение.
- **Правый клик:** те же «Open / Empty Recycle Bin», а ещё **Size text: left / bottom / right / top** — где показывать размер относительно значка.

## Прочие настройки в `Variables.inc`

Шрифт и размеры текста, ширина и скругление виджетов, отступ `Margin`, частота проверки обоев для Auto (`AutoCheck`), город и частота обновления погоды. Каждый параметр подписан комментарием прямо в файле.
